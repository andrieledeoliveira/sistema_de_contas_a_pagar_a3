# Sistema de Contas a Pagar

![Apache Maven](https://img.shields.io/badge/Apache%20Maven-C71A36?style=for-the-badge&logo=apachemaven&logoColor=white)
![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen?style=for-the-badge)

Projeto desenvolvido para a unidade curricular **Algoritmos e Programação**, da **Universidade do Sul de Santa Catarina (UNISUL)**, como parte da atividade **A3 – Desempenho de Compreensão**.

O objetivo é desenvolver um sistema para auxiliar no controle financeiro de uma empresa, permitindo o gerenciamento de contas a pagar e o acompanhamento de suas situações.

---

## Funcionalidades

- **CRUD:** inclusão, alteração, consulta e exclusão de contas a pagar.
- **Funções Auxiliares:** rotinas de apoio, validação, busca e organização de dados para o funcionamento do sistema.
- **Baixa de Contas:** registro de pagamentos parciais ou totais, com atualização do saldo devedor e da situação da conta.
- **Relatórios:** listagem de contas a pagar por período ordenadas pela data de vencimento, identificação de contas vencidas em atraso e balanço de despesas em um período selecionado.

## Objetivos do projeto

Aplicar conceitos de lógica de programação e algoritmos na resolução de um problema prático, utilizando sub-rotinas (procedimentos e funções), vetores e menus interativos para organizar os dados e facilitar a utilização do sistema.

O projeto é desenvolvido em grupo, seguindo os requisitos propostos na atividade acadêmica.
